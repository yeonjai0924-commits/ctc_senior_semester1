Week 9 / GameMaker

Before Mom Gets In

A first-person cleaning game. Mom is waiting outside the bedroom door, and you have 100 seconds to finish.

Clear eight objects from the desk to uncover a key. Use it to unlock the adjoining closet, then click the gold hanger to start a rhythm game. Press Space as the shirts reach the line to hang ten pieces of clothing.

Finish before the timer runs out to win. Otherwise, Mom breaks through the door.

Download GameMaker project (.yyz)

5.5 MB · Project download, not a browser-playable game.

How to run

  1. Download game_yeonjaisong.yyz.
  2. Open GameMaker LTS 2026 and select Import.
  3. Select the downloaded file and choose a new folder for the project.
  4. Select the appropriate target for your computer and click Run.

Controls

  • WASD / arrow keys: move
  • Mouse: look around
  • Click / E: pick up, place or interact
  • Q: put a held item back
  • Space: hang clothes in the rhythm game
  • Esc: pause
